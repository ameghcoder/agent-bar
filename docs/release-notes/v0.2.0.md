# AgentBar 0.2.0 - first public beta

AgentBar shows what your Claude Code sessions are doing in the GNOME top bar,
so you can work in another window and still know when Claude needs you.

**Requires:** Ubuntu 26.04 LTS, GNOME Shell 50 (Wayland), Claude Code.

## Install

```sh
sha256sum -c agentbar_0.2.0_all.deb.sha256      # should print: OK
sudo apt install ./agentbar_0.2.0_all.deb
agentbar install-hooks --apply
```

Restart Claude Code, log out and back in, then:

```sh
gnome-extensions enable agentbar@ameghcoder.github.io
agentbar doctor
```

Full instructions, what each state means, privacy details, and known
limitations are in the [README](https://github.com/ameghcoder/agent-bar#readme).
Changes are listed in [CHANGELOG.md](https://github.com/ameghcoder/agent-bar/blob/main/CHANGELOG.md).

## Upgrading from a 0.1.0 test build

Install as above, run `agentbar install-hooks --apply` once (it repoints the
hooks at `/usr/bin/node`), restart Claude Code, and log out and in.

## Rolling back

To go back to an earlier package, install it over this one:

```sh
sudo apt install --allow-downgrades ./agentbar_<older-version>_all.deb
```

To remove AgentBar completely:

```sh
agentbar uninstall-hooks --apply   # restores your Claude settings to their own entries
sudo apt remove agentbar
```

Your Claude settings, their backups, and `~/.local/state/agentbar/` are never
touched by the package.

## Integrity

The package is unsigned in this beta. Check it against the published
`agentbar_0.2.0_all.deb.sha256` before installing.
